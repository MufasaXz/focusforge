# FocusForge 1.0.4 · build 2032

Restores the floating pill navigation from before build 2031. Setup uses flat selection cards, shorter instructions, a compact plan preview and a single completion summary. Setup glow is removed; Home and timer play/pause/resume effects remain.

Focus → Manage now lets users remove subjects with confirmation. Completed sessions and earned time stay saved, including names on older sessions. Removing the selected subject clears its timer tag. If the subject belongs to the optional daily split, that split is cleared while the overall daily goal is retained; the confirmation explains this.

The leaderboard has a date range, personal standing, distinct leading ranks, clearer identity/level rows and a You badge. Sharing, reporting and hiding remain available; network failures show retry. Reference research used official Loop, Habitica and Medito APKs with REA. The research ledger records evidence and limitations; the leaderboard arrangement is original FocusForge design.

## Previous build 2031

Home keeps the daily goal and subject breakdown without a second subject-allocation card. New profiles start with no subjects selected: onboarding templates are suggestions, and only selected or manually added subjects enter the saved catalogue. Existing saved subjects are retained.

The weekly board now displays account levels alongside focus time, with more compact ranked rows, initials, and a highlighted personal row. Levels update when the account levels up. Older clients did not publish levels, so those rows show “Level unavailable” until that person opens an updated app and publishes their weekly summary. Opt-in text and the privacy screen describe the shared level.

The bottom navigation keeps the four destinations, tablet rail, screen-reader labels and coach anchors, with a bordered floating surface and clearer selected labels.
