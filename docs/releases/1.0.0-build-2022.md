## Changes

- Restored the historical Home timer button layout and slightly dimmed Focus pause/resume glow. The previously restored navigation and simplified setup remain in place.
- One Manage subject control opens a combined name-only add/remove sheet. Subject names infer matching icons; new subjects use an unused catalogue color. Removal preserves completed study history.
- Leaderboard opt-in card disappears after sharing is enabled. Sharing options move to the top-right menu; levels are shared. Hide/report member actions are removed. Signing out retains opted-in top-100 standings; explicit opt-out withdraws current and historical owned entries.
- Linked accounts privately back up subjects, custom plans, goals, profile/settings, totals and dated study sessions. Returning login restores these before opening account features and skips completed setup. Calendar-week progress restores recorded days, leaves absent days at zero and hides an empty week while retaining the saved goal.
- Guest Skip starts locally without waiting for network authentication. Existing verified same-account local state remains usable offline; uploads wait for successful server reconciliation.
- Failed unknown cloud reads cannot replace an existing backup with guest settings. Consent rollbacks and canceled restores cannot mutate a different account. Authentication changes stop old-account timer segments. Pending uploads retry while the originating account stays active.
- Shield overlay uses shorter copy and an unmasked app icon. Foreground recovery handles transient Overview activity. YouTube checks use visible exact resource IDs, subtree events and live filter/focus/grace decisions after asynchronous scans.
- Both supplied APKs were inspected with REA; they are identical Regain builds. Useful lifecycle and screen-recognition ideas were implemented independently. No reference source or assets were copied. See docs/shield-reference-findings-2022.md.
- Website privacy/deletion copy and cleanup coverage include private study backups. https://focusforgeorg.vercel.app/delete-account is deployed and its sign-in controls load without page errors. Updated Firestore rules were deployed and read back with an exact local match.

## Build support and remaining limits

Build with stable Flutter 3.47.6 / Dart 3.13.5, JDK 21, AGP 9.3.1 and Gradle 9.5.0. The pinned build-only Flutter Gradle plugin comes from official 3.50.0-0.1.pre sources; the app uses the stable SDK and engine. Vendored usage_stats runtime sources are unchanged. Licenses and patch notes are included under third_party. JDK 21 is required by the Android lint toolchain; lint remains enabled.

The reported missing Cupertino font, usage_stats Kotlin-plugin compatibility, obsolete Java 8 and legacy Android DSL warnings were addressed. Final APK/AAB Flutter build logs contain no warnings. Verbose native builds still expose upstream Gradle 10 Groovy-assignment deprecation notices from cached dependencies and a shared_preferences Kotlin redundant-null assertion warning. No warning suppression was added.

Settings/stats use whole-snapshot device timestamps for conflict resolution; simultaneous multi-device setting/XP edits are not merged per field. Dated sessions merge by ID. A backup must reach Firebase before uninstall/reinstall can recover it. Clearing local analytics does not delete its existing cloud backup; account deletion removes cloud records. Explicit opt-out is account-scoped locally; an older separately signed-in device can republish until its consent state is updated.

Static APK inspection and unit tests cannot establish recognition across all YouTube layouts or reliability on every OEM ROM. The separate Poco/VoltageOS report still needs real-device validation.
