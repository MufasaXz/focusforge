Processing applied to every file (all changes are permitted by CC0):

  * Trimmed to a 66-second window and rebuilt as a seamless loop: the
    1-second tail is crossfaded into the 1-second head, so the file's last
    sample is adjacent to its first sample in the source recording. This
    leaves no click, no fade and no silence gap at the loop point.
  * Downmixed from stereo to mono, resampled to 44.1 kHz.
  * Loudness-normalised to -23 LUFS integrated, with a look-ahead limiter
    at -2.5 dBFS so the whole set sits at a consistent level when mixed.
  * Encoded as MP3 (LAME), 96 kbps mono, 66.0 s, 774 KB each.

No other files in this repository were modified.
